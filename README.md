# Super30 Python Final Loop + Function Project

## Project Objective
This project combines Python loops, while loops, functions, lists, dictionaries, strings, conditions, validation, and error handling into 12 practical mini-programs.

## Programs Completed

| Task | Program | Main Concepts Used |
|---|---|---|
| 01 | Student Result Management System | Functions, lists, loops, input validation, conditions |
| 02 | Banking Application | Functions, while loop, lists, menu-driven programming, validation |
| 03 | Inventory Management | Dictionaries, functions, loops, searching, updating data |
| 04 | Quiz Application | Lists, loops, functions, score calculation, conditions |
| 05 | Number Analysis Tool | Lists, loops, functions, manual calculations, counters |
| 06 | Employee Salary Analyzer | Lists, functions, loops, average, filtering |
| 07 | Shopping Cart | Dictionaries, functions, while loop, CRUD-style operations |
| 08 | Password Strength Checker | Strings, loops, functions, Boolean flags, validation |
| 09 | Prime Number Analyzer | Functions, nested loops, ranges, conditions |
| 10 | Expense Tracker | Lists, dictionaries, functions, while loop, calculations |
| 11 | Mini Authentication System | Functions, while loop, retry logic, validation |
| 12 | Super30 Python Utility Application | Functions, while loop, menu, multiple utilities |

## How to Execute

Make sure Python 3 is installed.

From the repository folder, run any program with:

```bash
python task_01/student_result.py
```

Replace the path with the task you want to run.

Examples:

```bash
python task_02/banking.py
python task_04/quiz.py
python task_12/utility_application.py
```
